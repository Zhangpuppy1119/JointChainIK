# Unity 关节链 IK 演示

## 开发环境
Unity 2022.3.62f3c1

## 功能
- 支持创建 3～12 个关节，数量包含根节点和末端节点。
- 根节点位置固定。
- 使用鼠标左键拖动绿色末端节点。
- 通过 CCD IK 算法计算关节链姿态和各关节角度。
- 实时显示关节角度、末端误差和目标可达状态。
- 目标超出可达范围时，关节链向目标方向伸直。

## 运行方法
1. 下载或克隆本仓库。
2. 在 Unity Hub 中添加项目，选择包含 Assets、Packages、
   ProjectSettings 的项目根目录。
3. 使用 Unity 2022.3.62f3c1 打开项目。
4. 打开 Assets/Scenes/IKDemo.unity。
5. 点击 Play 运行。

## 操作方法
- 按住绿色末端节点并移动鼠标，拖动关节链。
- 点击 + 或 - 选择关节数量。
- 点击 Generate / Reset 重新生成关节链。
- 橙色表示固定根节点，红色表示目标位置。

## 算法说明
本项目采用 CCD（循环坐标下降）逆向运动学算法。
每轮从靠近末端的关节开始，依次计算
“关节到末端”和“关节到目标”两个向量的有向夹角，
再绕当前关节旋转后续节点，使末端逐步接近目标。
达到误差阈值或最大迭代次数后停止。

旋转过程保持各段连杆长度不变，根节点位置始终固定。
界面中的根部角度相对于世界坐标 X 轴计算，
其余关节角度相对于前一段连杆计算；
末端节点不单独计算转动角度。
